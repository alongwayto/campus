## 一、系统登录

### 1.1 访问系统

打开浏览器，输入系统地址（如 `http://localhost:3000`）进入登录页面。

### 1.2 登录操作

1. 在 **用户名** 输入框中输入账号（如 `admin`）。
2. 在 **密码** 输入框中输入对应密码。
3. 点击 **登录** 按钮。
4. 验证通过后，系统将跳转至主控制台（Dashboard）。

### 1.3 默认账号

| 用户名 | 密码 | 角色 | 权限说明 |
|--------|------|------|---------|
| admin | admin123 | 系统管理员 | 拥有所有功能权限 |
| maintainer | maint123 | 维护员 | 可处理故障、更新设备状态 |
| user1 | user123 | 普通用户 | 可查询设备、上报故障 |

> ⚠️ 首次登录后，建议立即前往 **系统管理 → 个人设置** 修改默认密码。

### 1.4 登出

点击页面右上角头像，在下拉菜单中选择 **退出登录** 即可安全登出。

## 二、设备管理

> **适用角色**：管理员（增删改查）、维护员（查询、更新状态）、普通用户（查询）

### 2.1 查看设备列表

1. 在左侧导航栏点击 **设备管理**。
2. 页面默认展示所有设备的分页列表，每页显示 10 条记录。
3. 列表字段说明：

| 字段 | 说明 |
|------|------|
| 设备名称 | 设备全称 |
| 设备类型 | 如计算机设备、网络设备等 |
| 所在位置 | 设备实际物理位置 |
| 状态 | 🟢 在线 / ⚫ 离线 / 🔴 故障 |
| 出厂编号 | 设备唯一序列号 |
| 厂商 | 设备制造商 |
| 保修到期 | 设备保修截止日期 |

### 2.2 筛选与搜索设备

在列表上方工具栏中：

- **关键词搜索**：在搜索框输入设备名称或序列号关键词，按回车或点击搜索图标。
- **按类型筛选**：在"设备类型"下拉框选择目标类型。
- **按状态筛选**：在"状态"下拉框选择在线/离线/故障。
- **重置**：点击"重置"按钮清除所有筛选条件。

### 2.3 查看设备详情

点击设备列表某行或行末的 **详情** 按钮，弹出设备详情面板，显示所有字段信息及最近故障记录。

### 2.4 新增设备（管理员）

1. 点击列表右上角 **+ 新增设备** 按钮。
2. 在弹出表单中填写以下信息：
   - **设备名称**（必填）
   - **设备类型**（必填，下拉选择）
   - **所在位置**（必填）
   - 序列号、厂商、购置日期、保修到期日、备注（可选）
3. 点击 **确认** 保存；点击 **取消** 放弃。

### 2.5 编辑设备（管理员/维护员）

1. 在设备列表中，点击目标设备行末的 **编辑** 按钮。
2. 修改相应字段信息。
3. 点击 **确认** 保存更改。

### 2.6 删除设备（管理员）

1. 在设备列表中，点击目标设备行末的 **删除** 按钮。
2. 在二次确认弹窗中点击 **确认删除**。

> ⚠️ 删除操作不可逆，删除前请确认该设备无待处理的故障记录。

### 2.7 批量导出

点击列表上方的 **导出 Excel** 按钮，将当前筛选结果导出为 `.xlsx` 文件。

## 三、故障管理

> **适用角色**：管理员（全权限）、维护员（处理故障）、普通用户（上报故障、查询自己提交的记录）

### 3.1 查看故障列表

1. 在左侧导航栏点击 **故障管理**。
2. 列表展示所有故障记录，支持按状态、严重程度、设备、时间段筛选。

故障状态说明：

| 状态值 | 状态名 | 说明 |
|--------|--------|------|
| 0 | 待处理 | 已上报，等待指派 |
| 1 | 已指派 | 已分配给维护员，待响应 |
| 2 | 处理中 | 维护员正在修复 |
| 3 | 已解决 | 故障已修复，等待确认关闭 |
| 4 | 已关闭 | 流程完成归档 |

### 3.2 上报故障（所有角色）

1. 点击 **+ 上报故障** 按钮。
2. 填写故障信息：
   - **关联设备**（必填，从下拉列表选择）
   - **故障标题**（必填，简短描述）
   - **详细描述**（建议填写，描述现象、复现步骤等）
   - **严重程度**：低 / 中（默认）/ 高
3. 点击 **提交** 完成上报；系统将自动发送通知给管理员。

### 3.3 指派维护员（管理员）

1. 在故障列表找到状态为"待处理"的记录，点击 **指派** 按钮。
2. 在弹出框中从"维护员"下拉列表选择负责人。
3. 点击 **确认指派**，故障状态更新为"已指派"，维护员收到通知。

### 3.4 处理故障（维护员）

1. 在故障列表中，找到指派给自己的记录，点击 **开始处理**，状态更新为"处理中"。
2. 完成修复后，点击 **标记已解决**，填写处理备注（如更换了何种配件、测试结果等）。
3. 状态更新为"已解决"，等待管理员或上报人确认。

### 3.5 关闭故障（管理员）

1. 确认维护员已解决问题后，点击 **关闭** 按钮。
2. 故障状态更新为"已关闭"，流程归档。

### 3.6 查看故障详情

点击任意故障记录的 **详情** 按钮，查看完整的处理时间轴，包括：
- 上报时间与上报人
- 指派时间与受派维护员
- 解决时间与处理备注

## 四、状态监控

> **适用角色**：所有角色可查看

### 4.1 总览看板

进入 **状态监控** 页面，顶部卡片展示实时汇总数据：

| 卡片 | 说明 |
|------|------|
| 设备总数 | 系统中所有设备数量 |
| 在线设备 | 当前状态为"在线"的设备数 |
| 离线设备 | 当前状态为"离线"的设备数 |
| 故障设备 | 当前状态为"故障"的设备数 |
| 待处理故障 | 未关闭的故障工单数量 |

### 4.2 设备状态列表

看板下方展示每台设备的实时状态：
- 绿色标记：在线（正常运行）
- 灰色标记：离线
- 红色标记：故障（点击可快速跳转至对应故障记录）

### 4.3 刷新数据

点击页面右上角的 **刷新** 图标可手动刷新监控数据；系统默认每 60 秒自动刷新一次。

## 五、数据分析

> **适用角色**：管理员、维护员

### 5.1 故障趋势分析

进入 **数据分析** 页面，"故障趋势"折线图展示近 30 天（可切换为近 7 天 / 近 90 天）的：
- 每日新增故障数
- 每日解决故障数

**操作**：在图表顶部选择时间范围，图表自动更新。

### 5.2 设备类型分布

"设备类型分布"饼图展示各类型设备的占比，鼠标悬停可查看具体数量。

### 5.3 故障严重程度分布

柱状图展示低/中/高三种严重程度的故障工单数量对比。

### 5.4 维修响应时长统计

表格展示各维护员的：
- 处理工单总数
- 平均响应时长（从指派到开始处理）
- 平均解决时长（从上报到关闭）

**用途**：评估维护团队效率，为人员调配提供参考。

### 5.5 导出报表

点击各图表右上角的 **导出** 按钮，可将当前图表数据导出为 Excel 或图片格式。

## 六、系统管理

> **适用角色**：仅系统管理员（admin）

### 6.1 用户管理

路径：**系统管理 → 用户管理**

#### 新增用户

1. 点击 **+ 新增用户**。
2. 填写用户名（唯一）、真实姓名、邮箱、手机号、密码，选择角色。
3. 点击 **确认** 创建；新用户可立即登录。

#### 编辑用户

点击用户列表中的 **编辑** 按钮，可修改用户信息（用户名不可修改）。

#### 重置密码

点击 **重置密码** 按钮，输入新密码后确认，系统将使用 BCrypt 重新加密存储。

#### 禁用/启用用户

点击用户行的 **启用/禁用** 开关，禁用后该账号无法登录，但历史数据保留。

#### 删除用户

点击 **删除** 按钮并二次确认，将永久删除该用户（建议使用禁用代替删除）。

### 6.2 角色管理

路径：**系统管理 → 角色管理**

系统内置三种角色，权限矩阵如下：

| 功能 | 管理员 | 维护员 | 普通用户 |
|------|:------:|:------:|:--------:|
| 设备增删改 | ✅ | ❌ | ❌ |
| 设备查询 | ✅ | ✅ | ✅ |
| 上报故障 | ✅ | ✅ | ✅ |
| 指派/关闭故障 | ✅ | ❌ | ❌ |
| 处理故障 | ✅ | ✅ | ❌ |
| 状态监控 | ✅ | ✅ | ✅ |
| 数据分析 | ✅ | ✅ | ❌ |
| 用户管理 | ✅ | ❌ | ❌ |
| 操作日志 | ✅ | ❌ | ❌ |

### 6.3 操作日志

路径：**系统管理 → 操作日志**

系统自动记录所有关键操作（登录、新增、编辑、删除等）。

日志列表字段：

| 字段 | 说明 |
|------|------|
| 操作用户 | 执行操作的用户名 |
| 操作类型 | 操作描述（如"新增设备"） |
| 请求接口 | 对应的 API 地址 |
| 请求参数 | 操作时提交的数据（脱敏处理） |
| 执行结果 | 成功 / 失败 |
| IP 地址 | 操作来源 IP |
| 操作时间 | 精确到秒 |

**查询日志**：支持按用户名、操作类型、时间范围进行筛选，支持导出为 Excel。

## 附录：常见问题

**Q：忘记密码怎么办？**  
A：请联系系统管理员重置密码（管理员在用户管理页面操作）。

**Q：设备状态显示错误怎么办？**  
A：管理员或维护员可在设备编辑页面手动修正设备状态。

**Q：上报的故障长时间没有响应怎么办？**  
A：请联系管理员在故障管理页面进行指派处理。

**Q：数据分析页面图表不显示怎么办？**  
A：尝试刷新页面；若问题持续，请联系管理员检查后端服务状态。
